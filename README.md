👨‍💻 Sobre mim
Sou Eduardo Souza, tenho 19 anos e curso Análise e Desenvolvimento de Sistemas. Meu foco é o desenvolvimento backend com Java, buscando construir sistemas robustos, escaláveis e bem arquitetados, com APIs RESTful, modelagem de dados relacional e boas práticas de versionamento.
